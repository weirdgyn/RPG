FreeActionsCounter x game (da visualizzare nel game status conta tutte le azioni /skill, /rolls, /attack, /move fatte da tutti i PC ed NPC fuori dal turno di combattimento, potrebbe essere utile un calcolo di FreeActionsCounter / ActionsPerRound / # tot personaggi).

Comandi:

/teleport X Y Z personaggio1, personaggio2, …  (master only) -> sposta un personaggio (anche np) in un dato punto sulla mappa (non conta come azione, non è soggetta a check di movimento)

/unlink -> scollega il giocatore dall'attuale personaggio (anche /link none)

/inventory -> produce un elenco dettagliato di tutto quello che possiede il giocatore

/buy item -> store.json (acquista un item dallo store, prezzo)

/pick item -> prende un item dalla mappa (se possibile)

/eval personaggio/npc -> produce un riassunto del livello personaggio effettuando somme dei valori di stats, skills + skillpoints, valori di inventario, money)

/upload personaggio -> lounge/triage (la scheda di un personaggio può essere uploadata dal client -> server ma non è immediatamente giocabile finisce nella zona triage per ispezione (valutazione parzialmente automatica, somma stats, somma skills + skillpoints, somma valori inventario, money).
